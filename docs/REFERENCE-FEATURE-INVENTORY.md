## 目的与边界

此表把两个参考快照与 Ome Music 当前代码、文档和可发布资源逐项对齐，是完整的功能现状、冲突/缺口与资产登记。未实现只描述差距，不代表拒绝移植；按 DEC-042，全部登记能力均进入分阶段移植计划，同时必须守住 AI 个人音乐与 DJ 私人电台的产品定位。当前阶段与顺序见 [参考功能移植路线图](REFERENCE-MIGRATION-ROADMAP.md)。

范围解释：表内引用 DEC-031 的“暂缓/不列移植计划”及较早批次对 MV、原生音频等能力的暂缓结论属于历史评估；DEC-042 已将这些能力纳入分阶段候选，不再表示从产品范围排除。是否已实现仍以各行状态和后续批次记录为准，先后顺序以路线图为准。

上游只作为功能和交互参考。Ome 当前采用 MIT 许可证，Folia 为 AGPL-3.0，ECHO Community 为 LGPL-3.0-only；本项目不直接搬运上游源代码、图像、字体、音频或其他可分发素材。需要相同能力时，在现有 Preact / Tauri / Rust 架构内独立实现，并记录所用外部依赖及其许可。

参考快照的素材逐文件路径、大小、SHA-256、许可说明和采用状态见 [参考项目素材登记表](REFERENCE-ASSET-REGISTER.md)；素材只登记元数据，不复制到产品。

本轮按两个仓库的本地快照盘点：Folia `chthollyphile/folia-major`，提交 `9cf8220`（2026-09-23，v0.7.8）；ECHO Community `Moekotori/ECHO`，提交 `d25d5c9`（2026-09-06，26.8.4）。快照位于工作区外的 `D:\Download\ome-reference\`，不参与构建或发布。ECHO 克隆包含一处既有测试快照改动；本项目未修改该克隆。

状态说明：**已实现**表示有可定位的实现；**部分实现**表示已有基础能力但和参考功能仍有差距；**待移植**表示尚无产品实现；**需专项设计**表示能力需要独立架构、权限、安全、性能或设备验收，按路线图阶段推进。

### 播放模式增量：随机播放与队列循环

Folia 与 ECHO 均提供队列随机与 off / one / all 循环模式。Ome 已在播放列表抽屉和 Ctrl+K 命令面板接入“打乱尚未播放曲目”和循环模式切换；随机操作保留当前曲目，循环偏好只在本机保存。AI 电台启用且 DJ 已配置时仍由本地画像选曲接管曲尾，队列模式控件暂停使用，不覆盖电台顺序。此项仅补齐普通队列聆听体验，不引入参考项目的自动混音、播放会话服务或扩展队列架构。

## 明确冲突与采用原则

| 冲突 | 处理 |
| --- | --- |
| Folia 使用 Electron/Web 服务与多部署后端，ECHO 使用 Electron 与常驻原生音频/扫描进程；Ome 是受轻量约束的 Tauri + Preact 应用 | 移植用户能力与交互契约，不复制整套宿主；原生音频/大扫描器另立方案，不增加前端运行时依赖 |
| ECHO Move Repair Lab 只有可信 file identity 且 dry-run 无 blocker 才能 apply；quick hash 明确只是低置信候选信号 | 当前 Windows stable Rust 标准库没有可用的稳定 file identity getter；不把相同首尾摘要/元数据提升成强身份，不自动合并或改路径。候选限制为最多 100 条且只显示低置信线索；后续 apply 需先具备经审查的可信身份实现和独立 dry-run/确认流程 |
| ECHO 标签工具会写音频文件，Folia 的实体展示修正则留在本地数据库 | 两种语义必须分开显示。数据库覆盖用于快速纠错；真实文件标签写入必须可备份/恢复、逐项授权并报告结果 |
| 上游支持多音源、下载器和插件，权限/版权模型各异 | 只接入官方授权的搜索/播放能力；不规避会员/访问控制，不默认下载受限内容；插件在权限沙箱设计完成前保持未启用 |
| Folia/ECHO 的可分发代码与媒体分别受 AGPL/LGPL 及各自资产许可约束 | 参考交互和功能；不直接复制代码、截图、图标、字体、歌曲、封面或其他资产，第三方依赖另行登记许可 |
