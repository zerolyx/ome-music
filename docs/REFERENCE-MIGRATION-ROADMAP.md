# Folia / ECHO 参考功能移植路线图

更新：2026-09-27 · 当前依据：DEC-042

## 不变的产品身份

Ome 仍是「不必选歌，按下播放就好」的 AI 个人音乐与 DJ 私人电台。此路线图扩展产品能力，不改上游云端仓库、`PROJECT.md` 的 Goal、首页主叙事或默认电台体验。新增能力应进入可选的从属视图或设置，不把首页变成媒体管理控制台。

DEC-031 记录的是先前的范围收缩，DEC-042 已取代其中对大类能力的排除。功能总账里的未实现项现在均可纳入移植批次；每项仍须尊重源项目和素材许可、现有文件授权、用户数据边界、故障回退以及仓库依赖规则。新依赖未经授权不安装。

## 分阶段移植

| 阶段 | 能力范围 | 接入原则与验收重点 |
| --- | --- | --- |
| 1. 本地电台与后台自动化 | 无 LLM 电台降级、曲库 watcher、后台扫描、诊断与移动修复 | 自动扫描只触及已授权目录；状态可暂停/查看；移动匹配先 dry-run、冲突/歧义不自动套用；索引维护不能删除音频。已补无 LLM 开机与曲尾画像选曲，并新增默认关闭、仅本次启动、前台且播放器空闲时运行的已授权曲库更新；目录 watcher 与后台移动修复仍待后续批次。 |
| 2. 远程个人曲库 | Navidrome/Subsonic、Jellyfin/Emby、WebDAV/SMB 等可访问曲库 | 进行中：Navidrome/Subsonic 已有显式连接、搜索、只读服务器歌单与最近专辑分页/详情、受限封面、原生歌词（行级/逐字/翻译/发音）及既有队列播放；Jellyfin 已增加当前曲目原生歌词（含校验后的逐字 cue）并复用现有舞台/桌面歌词；Jellyfin、Emby 已有会话级连接、音频搜索、受限分段播放、封面及只读专辑/歌单浏览；WebDAV 与 SMB 已接入显式会话、只读目录浏览、当前目录文件名过滤和既有队列播放，目录列表最多 500 项、音频 Range 每段最多 4 MiB。凭据仅驻 Rust 当前进程，不进入媒体 URL；远程曲目不进默认电台画像、历史或本地歌单。SMB 固定用户指定的单一主机/共享与 TCP 445，不启用 DFS；真实 SMB 服务端验收仍待环境。Emby 歌词仍待官方端点或真实服务证据。限制网络目标、超时和响应范围，连接故障不影响本地电台。参见 [WebDAV 只读曲库规格](superpowers/specs/2026-09-27-webdav-readonly-library.md) 与 [SMB 只读曲库规格](superpowers/specs/2026-09-27-smb-readonly-library.md)。 |
| 3. 视频与舞台扩展 | MV 候选、视频同步、清晰度、沉浸舞台控制和歌词外部控制 | Bilibili MV 面板已接入；用户显式搜索（最多 12 项）、选中后才取流。默认最高 720p，并可选择 360p/480p/720p；改变上限会为当前视频重新取流，UI 显示实际返回画质，服务端返回高于上限时拒绝加载。另支持仅针对当前本地曲目、只读检查已授权曲库邻近目录的 MP4/M4V/WebM 候选；扫描需用户点击，不联网、不递归、不暴露路径，播放使用有界 Range。视频静音并以音频为时钟；浏览器预览不调用 Tauri/网络。其他 Provider、更细同步和 Stage/Lyrics API 继续按阶段推进；MV 始终从属于当前音乐与歌词，播放失败保留音频。 |
| 4. 原生音频与扩展 DSP | 原生播放 host、gapless、WASAPI/ASIO/DSD、SRC/SDM、Limiter、耳机校正、FIR/APO | 单独架构阶段，不宣称未验证的 bit-perfect 或真峰值保护；需要设备矩阵、格式覆盖、CPU/内存/包体和与 DJ/TTS/睡眠/队列兼容性验收。 |
| 5. 插件与 Provider | 插件 manifest、权限、曲库/歌词/封面/元数据/音源 Provider、后台任务 | 先实现权限模型、隔离、限流、网络域名、数据卸载与审计；默认关闭第三方执行；卸载后明确清理其数据。 |
| 6. 同步、接口与丰富视觉 | 可选 Sync Server、主题同步、Now Playing / Stage / Lyrics API、AI 主题、壁纸、重型视觉器及发布部署 | 用户显式启用；同步范围可预览和撤回；默认不上传收听历史、路径或 DJ 记忆；大资源可选下载并提供空间/清理管理。 |

## 每批完成条件

- 对照 `REFERENCE-FEATURE-INVENTORY.md` 和 `REFERENCE-ASSET-REGISTER.md`，按用户能力独立实现，不复制 AGPL/LGPL 源码或未授权素材。
- 先检查既有 Cargo/npm 锁定依赖；新增依赖先说明必要性、替代方案、许可证、体积和维护成本，再取得授权。
- 对文件、账号、网络、插件执行、数据库和系统音频边界做安全审查；不输出密钥、Cookie、令牌或用户路径。
- 更新受影响的 UI/播放状态/API 和决策记录；涉及可见 UI 时执行设计简报、运行截图、交互/窄窗检查和视觉复核。
- 运行该阶段的小范围测试，再跑项目必要的构建、Lint、测试与原生检查；真实设备/服务无法验证时明确记录。

## 上游仓库保护

云端上游的产品定位与仓库文件保持只读。所有路线、状态、移植实现和决策只写入本地工作区；不执行远端推送、合并、发布或更改仓库描述。
