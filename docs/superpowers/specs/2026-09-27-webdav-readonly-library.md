# WebDAV 只读曲库接入规格

日期：2026-09-27 · 状态：已实现；`quick-xml` 0.39.4 直接依赖已获用户授权

## 1. 目标与产品边界

让用户可选连接自己的 WebDAV 文件库，在搜索/曲库次级入口浏览目录、筛选音频并通过现有队列播放。此能力属于远程私人曲库扩展；本地电台、网易云主路径、首页与 DJ 私人电台叙事不变。

WebDAV 不提供通用曲库搜索接口。本批只在用户当前打开的目录结果中本地筛选，不递归镜像整个服务器，也不把远程曲目导入本地索引或默认电台画像。

## 2. 用户流程

1. 用户在“设置 → 音乐源”手动填写 WebDAV 根地址及可选账号密码，明确连接。
2. Rust 端验证 URL 与访问范围后，在进程内保存当前会话；前端只得到已连接状态。
3. 用户打开搜索页的 WebDAV 来源，按需读取当前目录的直接子项；进入目录时再读取该目录，不预取后代。
4. 用户可在当前列表按文件名筛选，选择音频后沿用现有队列和播放控件。
5. 用户断开连接、关闭应用或连接新服务器时，清除会话与此前会话的媒体映射。

## 3. 协议和结果约束

- 使用 RFC 4918 `PROPFIND`，显式发送 `Depth: 1`；不发送 `Depth: infinity`。请求 `resourcetype`、`getcontentlength`、`getlastmodified` 与可用的显示名属性。
- 只接受成功的 `207 Multi-Status` 和可识别的 XML 响应；逐项解析 `href` 与 `propstat`，忽略属性读取失败的条目。
- 目录列表最多保留 500 项、响应体最多 2 MiB；过量或截断响应明确报错，不悄悄显示不完整结果。
- 文件只接受已登记的音频扩展名/媒体类型。文件名构成标题，当前目录名可作为专辑提示；不为目录列表额外读取文件内容或标签。
- XML 解析必须拒绝 DTD、实体声明和外部实体；RFC 4918 §20.6 明确指出外部实体不可信且可触发额外网络请求。
- `href` 必须解析为同一 scheme、host、有效端口，并位于用户配置的根路径之下。拒绝跨源、根目录逃逸、userinfo、片段与不安全编码路径。

## 4. 会话、网络和媒体安全

- 复用现有 Rust `reqwest` 客户端边界、服务器 URL 检查、超时和禁重定向策略；公网服务只允许 HTTPS，本机/局域网可使用 HTTP。
- 用户名密码仅用于会话请求认证，留在 Rust 进程内存；前端状态、数据库、本机偏好、日志、队列快照和 WebView 媒体 URL 均不含凭据。
- 前端获得不透明条目 ID；Rust 将其映射到已经校验过的根内 href，媒体请求不得接收任意 URL 或由 WebView 拼接服务器地址。
- 播放由既有 `ome-media` 代理承接单个有界 Range，拒绝多 Range、超限内容和非音频响应；不得把服务器重定向跟随到新主机。
- 连接/断开会增加会话代次，使迟到的目录、搜索或媒体响应失效。错误只显示安全摘要，不回显 Authorization、密码或完整请求头。
- 只读：禁止 PUT、PROPPATCH、MOVE、COPY、DELETE、MKCOL、LOCK 和 UNLOCK。

## 5. 依赖门槛

Rust `quick-xml` 0.39.4 已由用户明确授权并直接声明于 `src-tauri/Cargo.toml`；锁文件原本已有同一版本，无需升级其他依赖。解析器使用 DAV 命名空间感知读取、结构/事件/深度上限、仅允许预定义和数字字符引用，并拒绝 DTD 与自定义实体。不得改用手写的不完整 XML 解析器。

不新增前端运行时依赖，不要求数据库迁移或预置资源。SMB 作为独立协议接入后续批次，不能把 UNC 路径访问误记为完整 SMB Provider。

## 6. 验收清单

- URL 校验覆盖 HTTPS 公网、本机/私网 HTTP、无效 URL、凭据、跨源 href、编码的根路径逃逸和默认端口归一化。
- XML 覆盖命名空间前缀变化、默认命名空间、空目录、目录项、音频项、无效属性、超限响应、畸形 XML、DTD/外部实体拒绝。
- 连接、浏览、目录筛选、断开和切换服务器均验证会话代次；旧会话不能覆盖新状态。
- 媒体验证单 Range 上限、状态码、长度、音频类型、禁重定向及会话隔离；URL 和日志不出现用户名、密码或 Authorization。
- UI 验证桌面端可连接、浏览和入队，普通浏览器/演示模式显示桌面能力提示；窄窗口不横向溢出。
- 真实 WebDAV 服务器端到端连接尚未配置时，必须以协议层 mock 验收并在交接记录中注明该限制。

## 7. 参考依据

- [RFC 4918: HTTP Extensions for Web Distributed Authoring and Versioning](https://www.rfc-editor.org/rfc/rfc4918.html) — §9.1 PROPFIND、Depth 与 207 Multi-Status；§20.6 XML 外部实体安全考虑。
- Ome 当前远程会话与媒体代理实现：`src-tauri/src/subsonic.rs`、`src-tauri/src/jellyfin.rs`、`src-tauri/src/media.rs`。

## 8. 当前实现验收

- Rust 连接状态只保留在本次进程；根 URL、Basic Auth 凭据及 opaque ID 映射不写入 WebView、数据库、日志或偏好。
- 搜索页提供可选 WebDAV 目录浏览；当前目录按名称过滤，复用既有播放队列和媒体代理。断开/换会话会作废旧目录与音频映射；远程曲目不进入默认电台画像、历史或本地歌单。
- 本地 TCP 协议 mock 覆盖 Depth: 1、认证头、根目录与曲目列举、单 Range 音频响应；未连接真实 WebDAV 服务，需在有测试服务器后补端到端验收。
