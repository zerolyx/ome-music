# SMB 只读私人曲库接入规格

日期：2026-09-27 · 状态：已实现；真实 SMB 服务端验收待环境

## 1. 目标与产品边界

允许用户显式连接自己的 SMB2/SMB3 文件共享，在搜索页的从属曲库来源中按目录浏览音频，并交给 Ome 现有队列播放。该入口是个人曲库扩展，不改变默认 AI 电台、首页打开即听体验或 DJ 私人电台主叙事。

这不是本地网络扫描器，也不挂载整个共享。用户提供一个共享根（`\\主机\共享名`），应用只浏览该根下当前打开目录的直接子项，不递归建库、不自动发现其他主机，不把远程曲目写进本地索引、歌单、播放历史或默认电台画像。

## 2. 用户流程

1. 用户在“设置 → 音乐源”显式填写 SMB 主机、共享名、可选子路径、用户名和密码，然后主动连接。
2. Rust 桌面进程完成服务器握手和会话认证。连接表单在提交前短暂持有用户输入的凭据，连接成功后清空密码；前端之后只保存连接状态与不透明项目 ID，不持有 SMB 凭据或可直接访问的 UNC 地址。
3. 用户在搜索页选择 SMB 来源，浏览直接子目录、按当前列表的文件名筛选、选中音频并加入现有队列。
4. 断开、切换共享或退出应用时，关闭仍打开的文件/目录句柄、关闭 SMB client，并使旧目录结果和媒体 ID 失效。

## 3. 首批支持范围

- SMB 2.x / SMB 3.x，通过用户指定 DNS 主机名或 IPv4、固定 TCP 445 和共享连接；首批只实现显式用户名/密码会话。IPv6、Kerberos、匿名发现、域发现、多通道、DFS 自动跳转和 QUIC 不在首批范围。
- 目录列表仅请求直接子项；单目录最多 500 个服务器条目，超限返回明确错误而不静默截断。连接超时 10 秒，目录和单段读取的总时限各 30 秒；网络调用前后复核会话代次。同步 SMB 调用期间不能被中断，断开会先使旧代次失效并等待当前网络调用返回。
- 仅将允许的常见音频扩展名加入结果。首批使用路径名和文件尺寸作为展示资料，不递归读取文件标签/封面，不做后台同步。
- SMB 返回标记为 reparse point 的文件或目录一律跳过，避免符号链接、挂载点或虚拟重解析目标绕出用户选择的共享范围。
- 远程文件由随机不透明 ID 映射到经过校验的共享内路径；最多保留 20,000 个连接期映射。播放经既有媒体代理按需读取单个 Range，每段最多 4 MiB；不让 WebView 或前端传任意 UNC/网络 URL。
- 只打开已存在目标，并只请求通用读取权限。应用代码路径不得暴露 SMB 写入、覆盖、重命名、删除、创建目录或修改 ACL 操作。

## 4. 输入、路径和会话安全

- `host`、`share`、子路径分开解析与校验。拒绝 URL/URI 注入、空主机、非法 share、`.`/`..` 越界段、前导 UNC 混淆、控制字符、路径分隔符和无效路径；子路径不做 URL 百分号解码，`%` 作为普通 SMB 文件名字符处理。连接后也要确认列出的文件仍是配置共享根的后代。
- 默认只访问用户输入的单一服务器与共享，不自动跟随 DFS/referral 到未确认主机，不枚举局域网；目录结果也跳过 SMB reparse point，不沿服务器提供的重解析路径继续浏览。是否允许显式公共 SMB 地址和非标准端口须以用户可见选项/限制明确，不从路径字符串隐式解析认证信息。
- 不在持久前端状态、localStorage、SQLite、备份、队列快照、日志、错误详情或媒体 URL 写入账号密码/会话密钥。连接表单短暂持有输入值，成功后清空密码；会话凭据由 Rust 当前进程使用，断开时清理引用、关闭连接，不能宣称通用内存安全擦除。
- 每个返回的远程项目使用随机或不可推导 opaque ID，绑定单次连接代次与已解析共享内路径。切换连接时清除映射，迟到的 UI 请求和媒体读取均要复核代次。
- 为 SMB 操作设置明确的 Rust 端并发上限（每会话 Mutex 串行执行）、超时、目录响应上限和分段读取上限；错误仅返回安全摘要，不记录认证数据或完整 SMB 包。
- 只实现列目录、打开目标、读取属性及 `read_at`；读取前检查共享/路径后代、文件类型和文件长度；每个文件/目录句柄在所有成功、错误、取消和断开路径都显式关闭。

## 5. 依赖评估与门槛

- 当前 `src-tauri/Cargo.toml` 与 `Cargo.lock` 没有 SMB client。手写 SMB2/3 协议不安全且不现实；直接依赖现有网络文件系统能力也无法实现 SMB 协议，因此真正的跨平台只读 provider 需要客户端依赖。
- 候选 `smb = 0.12.1` 是纯 Rust SMB2/SMB3 client；docs.rs 于 2026-09-20 发布此版本，crate 下载源码包约 597.3 kB。此数值是 crate 源码包大小，不等于新增依赖总量、编译体积或安装包增量。
- `smb` 依赖自身 `smb-*` 协议 crate、`sspi`、密码学实现和异步运行时周边 crate；这是近期发布且 API/传递依赖可能继续变化的协议栈。代码应固定审查后的版本，并在 `THIRD_PARTY_NOTICES.md` 记录许可证与来源。候选项目仓库将该实现标为 MIT。
- `smb` 固定为 `=0.12.1`，用户已授权。已检查发布包 manifest：该 crate 要求 `async`、`multi_threaded`、`single_threaded` 三种运行模型只能择一；Ome 使用 `default-features = false` 并只启用 `multi_threaded`、`sign`、`encrypt`，由 Tauri blocking worker 承载同步调用。排除默认压缩、NetBIOS、QUIC/RDMA/Kerberos 和 Tokio 文件系统适配。锁文件新增 125 个解析包；上游 crate 许可 MIT，已登记于 `THIRD_PARTY_NOTICES.md`。

## 6. 测试与验收

- Rust 纯逻辑测试覆盖 DNS/IPv4 主机、共享根边界、路径分隔符、文件类型和 Range 请求边界；前端测试覆盖命令接线、路径 ID 保持不透明、列表曲目映射及断开后忽略迟到响应。
- 当前没有 mock SMB transport 或可控本地 Samba，因此未验证成功/失败认证、真实枚举、文件长度/偏移读取及 SMB 服务端句柄行为；真实 SMB 服务端可用后仍需进行端到端只读验证，特别确认错误/断开路径不发送写入操作。
- 验证用户名、密码和完整 UNC 不出现在 WebView 返回值、数据库、日志、偏好、错误消息和播放 URL；远程项目不能污染电台画像、历史、手动队列快照和本地播放列表。
- UI 只提供从属来源入口；桌面 Tauri 下连接与浏览，普通浏览器预览显示桌面能力提示；检查窄窗、键盘焦点、列表滚动和连接失败后本地播放可用。
- 真实 SMB 服务器未配置且没有可控协议 mock 时，只能报告纯逻辑/命令接线测试结果，并明确 SMB 握手、枚举和实际偏移读取未验收；不得把纯逻辑测试称为 mock 或端到端验收。
