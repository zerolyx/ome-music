# Plan 3「DJ」Implementation Plan — 记忆系统 + 电台编排 + 贴合人格的语音

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现灵魂功能：开机 DJ 欢迎词（语音+气泡）→ 自动开播 → 每首歌前电台式介绍 → 右侧抽屉随时对话。DJ 有本地记忆（对话摘要 + 事实卡 + 时段口味画像），LLM 未配置时优雅降级为画像评分自动电台。

**Architecture:** Rust `dj.rs`（LLM 调用 + 记忆 CRUD + 画像聚合 + 动作解析）+ 迁移 004（dj_messages/dj_memory_facts）；前端 `state/dj.ts`（signals）+ `DjDrawer` 抽屉 + `state/tts.ts`（speechSynthesis 封装）+ Settings 的 LLM/TTS 配置卡。

**Tech Stack:** 现有依赖全部够用（reqwest/serde/SQLite；TTS 用 WebView2 内置 speechSynthesis，零依赖）。

**Spec:** `docs/superpowers/specs/2026-09-21-ome-lightweight-personal-radio-design.md` §4（人格、记忆、三时刻、降级、**§4.5 语音贴合人格为硬性要求**）

## Global Constraints

- **人格（硬约束，进 system prompt 逐字）**："你是 Ome Radio 的深夜电台 DJ，一位温暖、克制、带一点文艺气质的主持人。永远用简体中文、短句说话，像人对人，不像播报机器。不堆形容词，不用表情符号，不夸张。介绍歌曲不超过两句。用户没说话时不要闲聊。"
- **TTS 贴合人格（用户特别要求）**：默认中文声线、rate 0.92、pitch 0.95（沉稳温柔）；设置页提供声线选择 + 语速/音高滑杆 + "试听"按钮播固定角色台词（"晚上好，欢迎回到你的音乐世界。"）；全程同一声线；TTS 不可用时静默降级纯文字气泡。
- **降级链**：LLM 未配置 → 纯画像评分电台（无语音无聊天，抽屉显示"DJ 离线模式（未配置语言模型）"）；LLM 调用失败 → 重试 1 次 → 规则动作兜底，绝不阻塞播放。
- **隐私**：对话与记忆只存本地 SQLite；LLM 调用仅发送必要上下文。
- **LLM 协议**：OpenAI 兼容 `POST {base_url}/chat/completions`，`Authorization: Bearer <key>`，body `{model, messages, temperature:0.8, max_tokens:300, response_format:{type:"json_object"} 可选}`；配置存 SQLite `app_config` 表（key/value），key 脱敏返回前端。
- **动作协议（LLM 输出 JSON）**：`{"say": string, "actions": [{"type":"play|queue|search_and_play|mood|none","query?":string,"mood?":string}]}`；解析失败→视作纯 say。
- **invoke 契约（camelCase）**：`dj_config() -> {configured, providerName, baseUrl, model, maskedKey}`；`dj_save_config({providerName,baseUrl,model,apiKey}) -> dj_config`；`dj_chat(history?) -> {say, actions}`（后端组装上下文并落库）；`dj_greeting() -> {say}`；`dj_intro(trackId) -> {say}`；`dj_memory_list() -> [{id,kind,content,weight,updatedAt}]`；`dj_memory_delete(id)`；`profile_hour_preferences() -> [{hour,plays,completions,skips}]`。
- **迁移 004**（新文件 `src-tauri/migrations/004_dj.sql`，IF NOT EXISTS 幂等）：`dj_messages(id TEXT PK, role TEXT NOT NULL CHECK(role IN ('user','dj','system')), content TEXT NOT NULL, created_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP)`；`dj_memory_facts(id TEXT PK, kind TEXT NOT NULL CHECK(kind IN ('pref','habit','fact','summary')), content TEXT NOT NULL, weight REAL NOT NULL DEFAULT 1.0, updated_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP)`；`app_config(key TEXT PK, value TEXT NOT NULL)`。
- 语音输入（STT）明确不做；不加前端依赖；UI 中文；每任务测试绿。
